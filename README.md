## about me

CS & Computer Engineering student at Dartmouth College, focused on software engineering, ML deployment, and NLP. I build practical systems end to end — full-stack web apps, automated data pipelines, and interactive learning platforms.

Currently a **Software Engineering Intern at Evergreen AI**, building NLP classification pipelines and safety guardrails for a student-facing wellness chatbot. I also do deep learning research in the **Mind Machines and Society Lab**, reviewing stereotypes and biases in multimodal models (CLIP, BLIP) and mitigation techniques like M4.

Outside the classroom, I run **Shamva Innovators**, a program teaching AI engineering to youth in Shamva, Zimbabwe — closing the tech access gap through hands-on Python, Streamlit, and AI API curriculum. I'm also actively practicing algorithmic problem-solving and always open to software engineering internships on complex, high-impact projects.
